# Build prompt · Market Intelligence (Pucho Code / coding agent — step 4)
The repo in `app/` already runs (`docs/db-setup.md`: a local PostgreSQL, `npm i && npm run db:migrate && npm run db:seed && npm run dev`; sign in with any persona in `db/seed/users.json`). Every page renders KPIs, charts, table and modals from `src/config/pages.js`; the Server Component in `src/app/[[...path]]/page.tsx` loads the rows and authorises the person. Do NOT edit generated files (`src/config/*`, `src/module/*`, `src/components/*`, `src/lib/*`, `src/app/*`); edit `os.yaml` and re-scaffold instead.

## Your job — the custom sections
Register each in `src/custom/index.js` (`export const CUSTOM = { EnquiryTimeline, MastersTabs }`), one component per file in `src/custom/`:
- none
Props: page-level custom gets `{ data, rows, reload, openModal(id, row) }`; detail-section custom gets `{ row, data, reload, openModal(id) }`. Use the kernel primitives only — every field gets `className="os-control w-full"`, every search/filter row is `<Toolbar>` — `DataTable`, `Modal`, `StatusBadge`, `GlassStatCard`, the primitives in `src/components/ui/primitives.jsx` (Chip, ChipRow, Avatar, Progress, Callout, Tile/Tiles, ScoreRing, IconDisc, ViewToggle, MetaRow, TagList), `renderSection` from `src/module/Sections.jsx`, the `CARD` class from `src/module/Charts.jsx`, antd `Button/Input/Select`, `toast` from sonner, `runAction(spec, payload)` / `callWorkflow(flow, action, payload)` from `src/utils/api.js` (they call the Server Action; the browser never talks to the database or to Studio). Colours come from tokens (`text-ink`, `text-ink-2/3/4`, `bg-surface-2`, `ok/warn/bad/info`, `brand-*`); never a hex literal.

## Design
Read `docs/frontend-design.md`, `docs/microanimations.md` and `docs/ux-laws.md` (seven UX laws: one primary action, 3 or fewer header actions, 7 or fewer items per group, show progress, familiar patterns) first. Use the generated tokens in `src/config/tokens.css` (the client's face, edges, canvas, radius — never a hex or a font name in a component), micro-interactions only from React Bits Micro ported per `docs/frontend-design.md`, white surfaces, quiet hairlines, consistent spacing, flat buttons, and restrained client brand #0B8F6A. Compose from the kernel primitives and blocks; do not add a UI package or a second component library. Keep adapters and scoped styles in `src/custom/**`. Reuse `src/config/motion.js` for purposeful microanimations and implement reactive reduced-motion handling for new custom effects. Preserve real loading/error/completion states and all role/data/action contracts. Record the frontend plan and observed review evidence in `docs/04-ui-ux.md`.

## Done when
`npm run build` clean; `python <pucho-os>/scripts/ui_check.py .` and `--mobile` report 0 failures; login/logout and every persona work. Inspect representative overview/records/detail screenshots and exercise responsive states, keyboard focus, and normal/reduced motion. Record actual observations and anything not verified.
